# SEFI-G2

SEFI-G2 is a fresh-generation intelligence architecture for mapping evidence-backed observations into expectation-centered thematic intelligence.

The core model is:

**Observation Fact → Expectation Expression → Expectation → Theme**

Entities attach horizontally, primarily to Expectation Expressions through typed relationships. Observation Facts remain evidence/source-of-truth records rather than Graph ML nodes.

## Current Status

SEFI-G2 is in the foundation phase. The repository currently establishes the minimal structure, constitutional principles, ontology, graph design notes, and conceptual database schema draft.

## Intentionally Not Implemented Yet

The foundation phase does not implement:

- Pipelines
- Dashboards
- Graph ML
- Live workflows
- SQL migrations
- Legacy SEFI-G1 code paths
- Governance-heavy layers

## Next Milestone

The next milestone is defining the Observation Fact → Expectation Expression mapping: how source-backed facts become concrete expectation expressions while preserving traceability and lightweight integrity.
