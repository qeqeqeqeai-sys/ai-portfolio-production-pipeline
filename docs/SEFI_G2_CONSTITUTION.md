# SEFI-G2 Constitution

SEFI-G2 is a new generation of SEFI, not a refactor of SEFI-G1. Legacy concepts, workflows, schemas, and assumptions are not automatically inherited. Any borrowed idea must be re-justified against the SEFI-G2 model before it becomes part of the system.

## Core Model

The foundational reasoning chain is:

**Observation Fact → Expectation Expression → Expectation → Theme**

- **Observation Facts** are evidence and source-of-truth records. They are not Graph ML nodes in the core model.
- **Expectation Expressions** translate observed facts into concrete expressions of market, business, structural, or thematic expectations.
- **Expectations** represent durable interpretive claims realized by one or more expectation expressions.
- **Themes** group expectations into higher-level intelligence areas.

Entities attach primarily to **Expectation Expressions** through typed relationships. Entities do not belong to themes or expectations.

## ML and Graph Compatibility

Graph-compatible ML is allowed later, but the core model must work without ML. SEFI-G2 must remain useful as a traceable intelligence model before any predictive, embedding, ranking, or graph-learning layer is added.

## Governance Principle

Governance must be lightweight and support capability; it must not dominate the architecture. No new layer should be added unless it creates intelligence or protects integrity.
