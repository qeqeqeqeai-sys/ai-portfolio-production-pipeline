## Transmission Pathway

Transmission Pathway is a structural route record. It answers whether movement could travel along a route. It is pathway-only and does not assert persistence, recurrence, intelligence, or prediction.

## Transmission Evaluation

Transmission Evaluation is a derived evidence-assessment record over an existing Transmission Pathway. It answers whether movement appears structurally supported along that pathway using bounded evidence and structural references.

Transmission Evaluation records reference `pathway_id`; they do not create, mutate, or duplicate Transmission Pathway records. Transmission Evaluation does not determine importance, significance, priority, impact, intelligence value, or ecosystem relevance.

## Transmission Memory

Transmission Memory is a later ontology layer for persistence and recurrence. It is explicitly separate from Transmission Evaluation.

## Boundary distinction

- Transmission Pathway = movement could travel.
- Transmission Evaluation = movement appears structurally supported.
- Transmission Memory = persistence/recurrence later.
