# P5-B Fragility Propagation Intelligence Report

## Objective
Add a deterministic descriptive layer after P5-A to quantify structural fragility distribution and connected propagation state.

## Scope
Consumes certified P5-A graph payloads and emits bounded propagation, pressure carrier, concentration, resilience corridor, pathway dominance, explainability, lineage, checksum, and certification artifacts.

## Non-goals
No prediction, no contagion forecasting, no expected-return modeling, no optimization, no recommendation/trading logic, no probabilistic modeling, no ML/graph-AI.

## Architecture placement after P5-A
P5-B is additive and downstream of the certified structural transmission graph.

## Deterministic propagation methodology
Fixed traversal depth (0..3), fixed attenuation schedule (1.00, 0.60, 0.35, 0.20), stable ordering, fixed tie-breakers, and bounded 0-100 scoring.

## Pressure carrier methodology
Ranks nodes as structural pressure carriers using load, breadth, persistence, explanation text, and lineage references to contributing edges.

## Fragility concentration methodology
Computes local node concentration, taxonomy-group concentration (subsector/type), system concentration, and concentration dispersion/breadth.

## Resilience corridor methodology
Scores each relationship corridor by stability, absorption, diversity, dependency, and erosion. Weakening is descriptive-only via deterministic indicator.

## Pathway dominance methodology
Detects dominant pathways, bottlenecks, amplifying/dampening relationships, and dependency-heavy corridors with deterministic bounded indicators.

## Explainability methodology
Uses deterministic template narratives only. No runtime model calls and no predictive or trading language.

## Replay/checksum methodology
Canonical stable JSON serialization, propagation policy checksum, lineage references to input checksums, deterministic output checksums, and replay-safe metadata.

## Certification gates
Status set: CERTIFIED/DEGRADED/BLOCKED. Gates include input graph presence, lineage availability, deterministic policy presence, bounded-score compliance, checksum presence, explainability boundary compliance, forbidden capability absence, additive-only behavior, and replay safety.

## Governance boundaries
Descriptive structural state only; no future claims and no decision directives.

## Final supervisor interpretation
P5-B provides institutionally interpretable maps of where structural fragility is concentrated and how it is distributed across connected topology at observation time.
