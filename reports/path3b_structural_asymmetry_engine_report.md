# P3-B Structural Asymmetry Engine Report

## objective
Implement deterministic additive structural asymmetry interpretation that combines Path 2 relative fragility intelligence with P3-A structural resilience intelligence.

## scope
Build a bounded interpretation engine that emits asymmetry dimensions, asymmetry state classification, explainability narratives, and certification metadata.

## non-goals
No trading recommendations, no trade execution, no portfolio allocation, no leverage logic, no alpha optimization, no expected return prediction, no autonomous strategy selection, no stochastic behavior, and no adaptive ML weighting.

## architectural placement
`transmission_layers/expectation_failure/path3b_structural_asymmetry_engine.py`

## relationship to P3-A
P3-A contributes resilience dimensions used to construct deterministic resilience support and persistence/divergence asymmetry views.

## relationship to Path 2 fragility intelligence
Path 2 contributes relative fragility, benchmark divergence context, concentration pressure, and breadth deterioration pressure.

## asymmetry methodology
P3-B computes bounded scores (0-100) for fragility pressure and resilience support, then derives downside and upside asymmetry dimensions using deterministic weighted composition and clamping.

## classification methodology
P3-B applies fixed tie-break ordering with deterministic thresholds to classify:
- BALANCED_STRUCTURE
- RESILIENT_TILT
- FRAGILE_TILT
- DOWNSIDE_ASYMMETRY
- UPSIDE_RESILIENCE_ASYMMETRY
- EXTREME_FRAGILITY_CONCENTRATION
- DIVERGENT_RESILIENCE

## explainability methodology
Template-based deterministic explanations include: fragility driver, resilience driver, balance interpretation, breadth/concentration interpretation, benchmark-relative interpretation, and bounded structural label.

## certification gates
Certification verifies deterministic replay, checksum stability, bounded scores, valid state labels, explanation completeness, additive-only integration, immutability, no prediction/execution/optimization behavior, no stochastic behavior, and forbidden capability exclusion.

## governance boundaries
P3-B is additive-only, replay-safe, checksum-traceable, deterministic, bounded, and institutionally interpretable.

## forbidden capabilities
No buy/sell/hold recommendations, no execution, no optimization, no portfolio action logic, no expected return outputs, and no adaptive model behavior.

## final interpretation
P3-B outputs bounded structural asymmetry interpretation only (for example: structural downside asymmetry is widening, resilience tilt persists, or fragility pressure dominates resilience support) and is not a trading engine.
